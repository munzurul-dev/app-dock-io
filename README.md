# appDock.io

A modern and responsive app discovery and management platform built with React.

## 🚀 Live Demo

https://appdock-io.netlify.app/

## Features

- 🔎 Search applications
- 📱 Dynamic app details
- ⭐ Dynamic ratings
- 📥 Install & uninstall apps
- 💾 LocalStorage support
- 📊 Sort by downloads & ratings
- 🔔 Toast notifications
- ⚡ Loading spinner
- 📱 Fully responsive design

## Tech Stack

- React
- React Router
- Tailwind CSS
- JavaScript
- React Icons
- React Hot Toast
- LocalStorage
- Vite
